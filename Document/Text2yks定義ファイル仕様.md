# Text2yks 定義ファイル仕様

Text2yks は、Yuka2 がテキストのスクリプト（.yks）をコンパイルする直前に、定義ファイルの**正規表現の置き換え規則**をスクリプトへ当てる前処理 DLL です。

- 置き換えは**行の中だけ**で行います。スクリプトの行数は変わりません（コンパイルエラーの行番号が元のスクリプトとずれません）。
- 正規表現は PCRE2 10.39（Perl 互換）です。
- 書き方の見本は `examples\Text2yks.txt`（テストで動くことを確かめています）。

## 1. 定義ファイル

| 項目 | 内容 |
|---|---|
| 名前 | `Text2yks.txt`（データフォルダ直下。ゲームの実行中のカレントからの相対名） |
| 無いとき | 何も置き換えない（エラーを1回出す） |
| 文字コード | UTF-8（BOM 有無どちらも可）・UTF-16LE（BOM 必須）。正しくない UTF-8（CP932 で保存したもの等）は**ファイルごと読まない** |
| 読み直し | 定義ファイル（`:include` 先を含む）の有無・大きさ・更新日時が変わると、次にスクリプトを読むときに読み直す |

### 1.1 1行の書き方

欄は **TAB 1つ以上**で区切ります。

```
// コメント（行頭の空白のあとが // の行）。空行は無視
:include<TAB>"ファイル名"
:define<TAB>名前<TAB>部分パターン
パターン<TAB>置き換え
パターン<TAB>置き換え<TAB>// コメント
```

- 行頭が `:` の行は命令です。`:` で始まるパターンは `\:` と書きます（`\:` は `:` そのものに一致します）。
- 行頭（空白のあと）が `//` の行はコメントです。`//` で始まるパターンは `\/\/` と書きます。
- 置き換えは2つめの欄の中身**そのまま**です（前後の空白も残ります。`//` も書けます）。
- TAB の後に何も無ければ、空文字への置き換え（一致した部分を消す）です。このときコメントは付けられません。
- 3つめの欄は `//` で始まるコメントだけ書けます。
- パターンにも置き換えにも TAB は書けません（パターンでは `\t` と書けます）。

### 1.2 `:include`

```
:include	"共通.txt"
:include	"sub/効果音.txt"
```

- 書いた位置に、そのファイルの規則が並びます（規則の順番は書いた順のまま）。
- パスは**読み込み元のファイルのフォルダ**からの相対です（絶対パスも可）。`"` は省略できます。
- 読み込みが循環しているとき・入れ子が16段を超えるとき・読めないときはエラーです（その行を飛ばして続けます）。

### 1.3 `:define` と `{名前}`

```
:define	NUM	[0-9]+
:define	PAIR	{NUM},{NUM}
P\(({PAIR})\)	pair:$1
```

- 以後のパターン（と部分パターン）の中の `{名前}` を部分パターンに置き換えます。
- 名前は英字か `_` で始まり、英数字と `_` が続くものです。
- パターン中の `{名前}` は**必ず参照**として扱います。定義されていない名前ならその規則はエラーです。`{` をそのまま書くときは `\{` と書きます。
- 次の PCRE2 の書き方の `{…}` は参照ではありません: `\p{…}` `\P{…}` `\x{…}` `\o{…}` `\g{…}` `\k{…}` `\N{…}`。数の指定 `{2}` `{1,3}` も参照ではありません。
- 同じ名前をもう一度定義すると警告を出して上書きします。`ARG` と `T2Y_` で始まる名前は予約です。

### 1.4 組込みの `{ARG}`

旧エイリアス（`alias*.txt` の `命令(%1,%2)`）の引数1個と同じ切り方をします。

- 前後の**半角空白**を含みません（タブは含みます）。空でも一致します。
- 括弧の入れ子（`f(x,y)`）と `"…"` の中の `,` `(` `)` は区切りにしません。
- `{ARG}` 自体はグループを作りません。値を使うときは `({ARG})` と書きます。

```
@VOICE *\( *({ARG}) *, *({ARG}) *\)	SoundCreate(Layer=$1, File="VOICE\$2", Play, Stream)
```

`@VOICE( 1 , "a,b(c" )` → `SoundCreate(Layer=1, File="VOICE\"a,b(c"", Play, Stream)`

> `{ARG}` を使うと、パターンの末尾に括弧の数え方の定義 `(?(DEFINE)(?<T2Y_PAREN>…))` が足されます。番号は利用者のグループの後ろなので `$1` 以降はずれません。

## 2. パターン（PCRE2）

- 文法は PCRE2（Perl 互換）です。後読み・名前付きグループ・再帰・`\p{Han}` などが使えます。
- UTF-8 の文字単位で照合します（日本語1文字・BMP 外の文字1文字が `.` 1つ）。
- 大文字小文字は区別します（区別しないときは `(?i)`）。
- `\d` `\w` `\s` は **ASCII のみ**です（全角数字・漢字・全角空白には当たりません）。日本語の文字種は `\p{Han}` `\p{Hiragana}` `\p{Katakana}` などで書きます。
- `$` は行末、`^` は行頭です（1行ずつ照合するため）。
- 使えないもの: パターン先頭の `(*LIMIT_HEAP=…)` `(*LIMIT_MATCH=…)` `(*LIMIT_DEPTH=…)`・`\C`・`T2Y_` で始まるグループ名。
- 照合の上限（回数100万・深さ1万）を超えたときは、その規則をその行では当てずにエラーを出します。

## 3. 置き換えの書式

| 書き方 | 意味 |
|---|---|
| `$1`〜`$99` | その番号のグループ。2桁はそのグループがあるときだけ2桁と読む（グループが5個なら `$15` は `$1` と `5`） |
| `$&` | 一致した全体 |
| `$$` | `$` 1文字 |
| それ以外の `$`・`\` | そのまま（`"BG\$1.png"` はそのまま書けます） |

- 値の無いグループ（`(x)?` が当たらなかった等）は空になります。
- パターンに無い番号を使うとエラーです。

## 4. 置き換えの動き

1. スクリプトを `\r\n`・`\n`・`\r` で行に分け、**行の中だけ**で照合・置換します。改行コードは元のまま残ります。
2. 1周: 行の左から、**すべての規則の中で最も左で始まる一致**を置き換えます。同じ位置で始まる一致が複数あれば、**定義が先の規則**を使います。置き換えた部分はその周では見直しません（後読みは置き換える前の行を見ます）。
3. `"…"` の中に**始まる**一致は当てません（`"` から次の `"` の手前まで。閉じない `"` は行末まで）。閉じる `"` の位置から始まる一致は当てます。
4. 長さ0の一致は使いません。
5. 行が変わった間は周回を繰り返します（入れ子のマクロが展開されます）。同じ文字列への置き換えは「変わった」と数えません。**32周**しても変わり続けるときは循環とみなし、32周目の結果を使ってエラーを出します。
6. 正しくない UTF-8 を含む行は置き換えません（Yuka2 は変換済みの UTF-8 を渡すので通常は起きません）。

## 5. エラーの出方

- エラー・警告は英語で `OutputDebugStringW` へ出ます（DebugView などで見られます）。形式: `Text2yks: error: <ファイル>(<行>): <内容>`
- 定義の誤りはその行（規則）だけ飛ばし、ほかの規則は使います。
- 1回の呼び出し（スクリプト1本）で出す照合中のエラーは20件までです。

### 5.1 主なエラーメッセージ

| メッセージ（`Text2yks: error: <場所>: ` の後） | 意味 |
|---|---|
| `cannot read definition file: "…"` | 定義ファイル（`:include` 先を含む）が無い・読めない |
| `file is not valid UTF-8 (…); the whole file is ignored` | UTF-8 として正しくない（CP932 で保存した等）。ファイルごと使わない |
| `file is not valid UTF-16LE; the whole file is ignored` | UTF-16LE の BOM があるが中身が正しくない |
| `include cycle: "…"` | `:include` が循環している |
| `include nesting is too deep (more than 16): "…"` | `:include` の入れ子が深すぎる |
| `:include needs one file name …` / `:define needs a name and a pattern …` | 命令の欄の数が違う |
| `invalid name for :define: "…"` / `name is reserved: "…"` | `:define` の名前の誤り（`ARG`・`T2Y_…` は予約） |
| `unknown directive: "…"` | `:` で始まる行の命令が分からない（パターンなら `\:` と書く） |
| `missing TAB between the pattern and the replacement` | パターンと置き換えの間に TAB が無い |
| `empty pattern` | パターンが空（行が TAB で始まっている） |
| `unexpected text after the replacement (a comment must start with //)` | 3つめの欄が `//` で始まっていない |
| `undefined name {…}` | 定義されていない `{名前}` |
| `invalid pattern: …` | 正規表現の誤り（PCRE2 のメッセージと位置。位置は `{名前}` を展開した後のバイト位置） |
| `replacement refers to $n but the pattern has only m group(s)` | 置き換えがパターンに無いグループを使っている |
| `(*LIMIT_...) at the start of a pattern is not allowed` / `group names starting with T2Y_ are reserved` | 使えない書き方 |
| `matching stopped (…) for the rule at <ファイル>(<行>): the rule is not applied to this line` | 照合の上限を超えた（その行ではその規則を当てない） |
| `replacement did not settle after 32 passes …` | 32周しても置き換えが止まらない（規則が互いに置き換え合っている） |

`Text2yks: warning: … {名前} is redefined` は警告（上書きして続ける）、`Text2yks: info: loaded N rule(s) from M file(s)` は定義を読んだお知らせです。

## 6. 数値と制限

| 項目 | 値 |
|---|---|
| 1行の周回の上限 | 32周 |
| 照合の上限 | 回数 100万・深さ 1万（1回の照合ごと） |
| `:include` の入れ子 | 16段まで |
| 1回の呼び出しで出す照合中のエラー | 20件まで（残りは件数だけ） |
| 置き換えのグループ番号 | `$1`〜`$99` |

- **置き換えに TAB は書けません**（欄の区切りになるため）。パターンには `\t` と書けます。
- 置き換えの中で改行は作れません（行数を変えないため）。
- 行をまたぐ一致はできません。
- 置き換えの `\` は特別扱いしません（`\n` も `\` と `n` の2文字です）。

## 7. 旧エイリアスからの書き換え

`tools\alias2text2yks.ps1` で変換できます。手で書くときは次のとおりです。

| 旧エイリアス（alias*.txt） | Text2yks.txt |
|---|---|
| `@WAIT<TAB>Wait(Time=500)` | `@WAIT<TAB>Wait(Time=500)` |
| `@BGMStop()<TAB>SoundStop(Layer=1)`（括弧付きの固定文字列） | `@BGMStop\(\)<TAB>SoundStop(Layer=1)` |
| `@BG(%1)<TAB>GraphicCreate(…File="BG\%1")`（引数1個） | `@BG *\( *+(?!\))({ARG}) *\)<TAB>GraphicCreate(…File="BG\$1")` |
| `@VOICE(%1,%2)<TAB>…%1…%2…`（引数2個以上） | `@VOICE *\( *({ARG}) *, *({ARG}) *\)<TAB>…$1…$2…` |
| `@TA(%1,%2,C)<TAB>…`（固定値の引数） | `@TA *\( *({ARG}) *, *({ARG}) *, *C *\)<TAB>…` |
| `Bs(%1,%2,)<TAB>…`（空の固定値） | `Bs *\( *({ARG}) *, *({ARG}) *, *\)<TAB>…` |

- 旧エイリアスは `名前()`・`名前( )` を「引数0個」とみなし、引数1個のエイリアスには当てませんでした。`*+(?!\))` はそれと同じにするための書き方です。
- 置き換えの `$` は `$$` と書きます。
- 旧エイリアスの規則の順番（同じ位置で当たるときの優先順）はそのまま保ちます。

## 8. 旧エイリアス（alias*.txt）との違い

| 項目 | 旧エイリアス | Text2yks.txt |
|---|---|---|
| 書き方 | `命令(%1,%2)<TAB>置き換え` | 正規表現と `{ARG}` |
| 文字コード | BOM 無しだと CP932 として読む | UTF-8／UTF-16LE。CP932 は読まない |
| コメント | 行のどこでも `//` から後 | 行頭の `//`・3つめの欄の `//` だけ |
| 引数の区切り | `"…"` の中の `,` も区切る | `"…"` の中は区切らない |
| 改行をまたぐ引数 | 行を詰めてしまう | 行をまたいでは一致しない（行数は変わらない） |
| 同じ文字列への置き換え | 止まらない（無限ループ） | 変化と数えない |
| 循環 | 止まらない | 32周で打ち切ってエラー |
